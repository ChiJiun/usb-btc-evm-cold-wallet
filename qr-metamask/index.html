Sepolia 測試網功能預覽（尚未完成實機驗收）。此頁面只處理公鑰／未簽交易／已簽交易；不可輸入助記詞、私鑰、密碼或 Vault。請僅在可信任且物理斷網的電腦執行。

① 與 MetaMask 配對

先在離線 CLI 執行 usb-cold-wallet --vault /offline/wallet.vault export-keystone-public --out public-evm.json，再匯入這份公開資料。

配對後、入金或簽署前，必須驗證 MetaMask 實際選中的完整地址。 Keyring 可能顯示多列重複地址；禁止使用任何與上方不同的地址。

② 從 MetaMask 掃描待簽交易

MetaMask → Connect Hardware Wallet → QR-based，使用上面的配對 QR；只使用與可信離線端完全相同的 index 0 地址；列表可能有多個重複地址列，出現任何不同地址都應中止配對。要轉帳時，掃描 MetaMask 顯示的 ur:eth-sign-request。

尚無交易

必須在離線可信螢幕，根據獨立來源確認完整收款地址、金額及手續費。 QR request 本身不是授權。

③ 載入已簽交易並回傳 MetaMask

使用離線 CLI：usb-cold-wallet --vault /offline/wallet.vault sign-evm --tx unsigned.json --to 已獨立確認地址 --wei 已確認整數金額 --expected-policy-sha256 已獨立記錄的SHA256 --out signed.json。不得在連網電腦執行簽署。
